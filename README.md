# ClashStone

ClashStone is a 2D medieval action game with pixel-art environments, enemy combat, houses, towers, rivers, and a fantasy kingdom to explore.

## 🎮 About the Game

Explore the world of ClashStone, move through the kingdom, and face enemies in a medieval setting. The game features a handcrafted map with buildings, natural environments, and combat gameplay.

## ✨ Features

- 2D pixel-art world
- Medieval houses and towers
- Rivers, trees, rocks, and other map details
- Enemy AI and combat
- Player movement and animations
- A fantasy kingdom to explore

## 💻 Download

Download the Windows version from the **Releases** section of this repository.

1. Download the ZIP file.
2. Extract the folder.
3. Open `ClashStone.exe` to play.

Make sure all exported game files stay together in the same folder.
